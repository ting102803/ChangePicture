# ChangePicture

한글 문서 사진을 OCR로 방향 교정하고 1MB(1,000,000바이트) 이하 JPG로 변환하는 Streamlit 앱입니다.

## 실행

Python 3.12와 Tesseract OCR이 필요합니다. Windows 기본 설치 경로인
`C:\Program Files\Tesseract-OCR\tesseract.exe`는 자동 인식하며, 다른 경로는 PATH에 추가하세요.
저장소의 `tessdata/kor.traineddata`를 한국어 인식에 사용합니다.

```sh
pip install -r requirements.txt
streamlit run app.py
```

Docker 환경에서는 다음 명령으로 실행하고 http://localhost:8501 에 접속합니다.

```sh
docker compose up --build
```

## 처리 동작

- 자동 회전은 4방향 한국어 OCR 점수를 비교합니다. 점수가 낮거나 1·2위 차이가 작으면 OCR 회전을 생략하고 확인 메시지를 표시합니다. EXIF 적용 옵션이 켜져 있으면 EXIF 방향 보정은 먼저 수행합니다.
- OCR 실행 오류는 해당 파일의 실패로 표시합니다. 각 OCR 호출의 제한 시간은 20초이며, 압축 전용 모드에서는 OCR이 필요하지 않습니다.
- 압축 전용 모드는 EXIF 방향을 픽셀에 반영해 원본의 표시 방향을 유지합니다. 모든 출력에서 EXIF/GPS 등 원본 메타데이터를 제거합니다.
- 투명 PNG는 흰색 배경에 합성합니다. JPEG 품질 95부터 40까지 시도하고, 그래도 크면 해상도를 15%씩 줄여 재시도합니다. 해상도를 줄인 경우 경고를 표시합니다.
- 같은 이름으로 변환된 파일은 `문서_2.jpg`처럼 번호를 붙여 ZIP 내부 덮어쓰기를 방지합니다.
- 동시에 처리하는 이미지는 최대 6개이며, Tesseract 내부 스레드는 작업당 최대 3개로 제한합니다(OMP_THREAD_LIMIT=3).

갱신 후에는 Streamlit 프로세스를 종료하고 다시 실행하세요. 앱은 기존 OMP_THREAD_LIMIT 값도 3으로 갱신합니다. Docker 환경에서는 컨테이너를 새 이미지로 다시 생성하세요.

## 캐시와 디버깅

요청에 따라 **이미지 처리 캐시 초기화 버튼을 유지**했습니다.
캐시 키는 파일 내용·파일명·옵션·`image_processor.py` 내용의 SHA-256을 포함합니다.
처리 코드를 변경하면 이전 결과와 다른 캐시 키를 사용합니다. 실패한 처리는 캐시하지 않습니다.
캐시는 최대 64개 결과를 1시간 보관하며, 새 사용자 접속 시 자동 초기화하지 않습니다.

초기화 버튼은 서버 전체 Streamlit 데이터 캐시를 지웁니다. 여러 사용자가 접속하는 환경에서는 다른 사용자의 캐시도 지워집니다.
초기화 뒤 현재 업로드 파일은 화면 재실행 과정에서 다시 처리됩니다.

## 검증

```sh
python -m unittest discover -s tests -v
```

15개 테스트로 용량 제한과 해상도 축소, EXIF 8가지 방향과 메타데이터 제거,
투명 PNG, OCR 실패·모호한 판단, 파일명 중복, 캐시 갱신과 수동 초기화,
Streamlit 시작 화면 및 옵션을 확인합니다.

Windows 맑은 고딕과 실제 Tesseract를 사용하는 추가 확인:

```sh
python tests/real_ocr_check.py
```

합성 한글 문서를 0·90·180·270도로 돌려 보정 각도를 검사하고, 빈 이미지가 경고와 함께 유지되는지 확인합니다.
방향 점수 기준(최소 100점, 1·2위 차이 50점 이상 및 최고 점수의 15% 이상)은 초기 보수적 기준입니다.
실제 병원 문서·스마트폰 사진에 대한 정확도와 가독성은 별도로 검증해야 합니다.
Docker 이미지는 이 변경에서 직접 빌드 검증하지 않았습니다.
